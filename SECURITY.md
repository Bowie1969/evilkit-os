# Security policy

EvilKit is a research alpha for authorized security testing. Do not use public
issues to report a vulnerability that includes exploit details, credentials,
client information, target addresses, or other sensitive evidence.

Report security issues privately to **fullchecksecurity@gmail.com**. Include the
affected version or commit, impact, reproduction steps using a safe local
fixture, and any suggested remediation. You should receive an acknowledgement
within five business days.

Version 1.2.x is the currently supported research line. Earlier versions may
receive a fix only when the same issue affects 1.2.x.

Testing this repository does not authorize testing any third-party system.
Please use local fixtures or an environment you own and are permitted to test.
